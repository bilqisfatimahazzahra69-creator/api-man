API Documentation

Integrate Fetcher media downloader into your own applications easily.

1. Fetch Media Info

Get download links and metadata for any supported URL.

GET /api/download?url={YOUR_URL}
Headers:
  x-api-key: YOUR_API_KEY

2. Response Object

{
  "title": "Cool Video",
  "thumbnail": "https://...",
  "download_url": "https://...",
  "platform": "TikTok",
  "media": {
    "all_formats": [...]
  }
}

3. Request Progress

Poll progress for best quality processing.

GET /api/progress?taskId={TASK_ID}
